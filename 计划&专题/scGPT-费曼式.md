# scGPT · 费曼式学习

> 以费曼式对话（直觉优先、公式随后）掌握 scGPT 单细胞基础模型：从 scRNA-seq 地基 → 架构解剖 → Kaggle 实战 → 基准批判 → 前沿巡礼，并借此深挖 Transformer、补齐 ML/PyTorch/pandas/numpy 工具箱，形成可迁移到其他基础模型（Geneformer、UCE、LeCun JEPA/世界模型）的学习模板。

## 方法论

**继承自分析力学计划**：提问启动 → 概念探索 → 练习验证 → 思考扩展；里程碑勾选；复盘区。

**新增机制**：

1. **节点状态机**：⬜未开始 → 🟨进行中 → 🟩已完成。完成即打标（记录日期到进度日志），自动递推下一节点。
2. **"完全理解"三准则**（费曼测试，全过才打标）：
   - 能用自己的话向外行讲清该概念
   - 能说出它**不是什么**（举反例、指出常见误解）
   - 能迁移：换数据集/换任务/换模型仍会用
3. **节点六要素模板**：🗺️ 高屋建瓴定位（知识图谱位置+前置+去向）｜🎭 多角度理解（NLP 视角/生物学视角/工程视角）｜✅是什么 ❌不是什么｜🔭 前沿连接｜✍️ 练习（概念题+代码题+Kaggle 题）｜🚦 完成判据
4. **间隔复习队列**：已完成节点在第 1/3/7 天进入每日提醒的快速回顾。
5. **误解本**（见文末）：持续收集"不是什么"中踩过的坑。
6. **前沿雷达**：每周查一次 arXiv/Nature 单细胞基础模型进展。

## 课程地图（4 阶段 11 节点）

### 阶段 0 · 地基

- **N0 scRNA-seq 数据基础**：表达矩阵、稀疏性、归一化、HVG、PCA/UMAP、细胞类型注释。
  🔭 高屋建瓴：scGPT 的一切输入输出都长在这层地基上；不懂矩阵结构，后面全是空中楼阁。
  🛠️ 工具箱：numpy 稀疏矩阵、pandas DataFrame、anndata（AnnData 对象）。
- **N1 Transformer 与语言模型（深挖节点）**：token、注意力、位置编码、MLM vs 自回归。
  🔭 核心问题："把基因当单词、细胞当句子"这个隐喻的边界在哪里？哪里会失效？
  🛠️ 工具箱：PyTorch nn.MultiheadAttention 手写一遍注意力。

### 阶段 1 · scGPT 核心

- **N2 基础模型范式**：是什么/不是什么；与任务专用模型（scVI、Harmony）的本质区别。
- **N3 scGPT 架构解剖**：基因 token、表达值分箱、masked cell modeling、预训练检查点。
  🔭 对照 N1：为什么选 BERT 式掩码而非 GPT 式自回归？（接 LeCun 线索 X1）
- **N4 预训练任务与数据**：CELLxGENE ~3300 万细胞、基因排序策略、数据偏差。
- **N5 下游微调三任务**：细胞类型注释、批次整合、扰动预测。

### 阶段 2 · 实战（Kaggle Notebook GPU 环境）

- **N6 上手跑通**：Kaggle GPU 上跑 scGPT 官方教程，产出嵌入 + 细胞注释。
- **N7 Kaggle 实战**：Open Problems – Single-Cell Perturbations 数据集 + CZI「Benchmarking Single-Cell Foundation Models」竞赛复现基线。
- **N8 扰动预测专题**：scGPT vs GEARS vs CPA；先跑 Train Mean 基线再上模型（N9 的伏笔）。

### 阶段 3 · 前沿与批判

- **N9 基准争议（批判性节点）**：多项 2025 基准显示 Train Mean/线性基线/PCA 击败 scGPT——为什么？是模型问题、数据问题还是评测问题？
  🔭 必读：Nature Methods 2025（线性基线）、PertEval-scFM（ICML 2025）、BMC Genomics 2025。
- **N10 前沿模型巡礼**：UCE（Nature 2026，bag-of-RNA + ESM2 蛋白嵌入）、Geneformer、scFoundation、GenePT、scGPT 机制可解释性（造血流形发现，arXiv 2026）。
- **N11 毕业项目**：独立复现一个基准结论，产出自己的评测报告（含"不是什么"章节）。

### 线索 B · Transformer 架构对照表（N1/N3 填充）

| 维度 | BERT 式（scGPT） | GPT 式（自回归） | JEPA 式（LeCun） |
|---|---|---|---|
| 预测目标 | 掩码 token | 下一 token | 表征空间中的未来 |
| 生成 vs 判别 | 双向 | 单向 | 非生成 |
| 在单细胞的化身 | scGPT | scFoundation | （开放问题） |

### 线索 C · 迁移学习模板（学完 N11 后抽象固化）

学任何新基础模型的五步：① 它的"单词/句子"是什么 → ② 预训练任务是什么、为什么 → ③ 零样本能做什么、不能做什么 → ④ 跑一个最小基线对比 → ⑤ 写"是什么/不是什么"卡片。
适用对象：Geneformer、UCE、蛋白 LLM（ESM）、LeCun JEPA/世界模型。

### 线索 X1 · LeCun 世界模型 / JEPA（交叉前沿）

LeCun 主张：自回归生成式模型学不到世界模型，应在**表征空间**预测（JEPA）。对照思考：
- scGPT 的掩码基因预测是 token 空间生成——它学到的是"基因语法"还是"细胞世界模型"？
- UCE 的 CLS 嵌入 vs JEPA 的预测式嵌入，谁更接近"表征空间预测"？
- 此线索不设独立节点，在 N3/N9/N10 中反复回扣。
