## 3. 执行协议（接手教学的 agent 照此操作）

### 3.1 如何定位当前节点
1. 读计划正文「里程碑」章节；
2. 第一个 `- [ ]` 未勾选项 = 当前节点（N1 已是当前）；若全勾选 → 进入结课复盘。

### 3.2 四段式交互流程（每个节点内部按此推进）
1. **① 提问启动**：抛 2-3 个无需专业知识的直觉问题，等学习者用"我觉得…"回答；
2. **② 概念探索**：先诊断其回答（逐条：哪对哪偏），再顺着直觉展开，先图像后公式；每讲一个概念套用「✅是什么 / ❌不是什么」；
3. **③ 练习验证**：布置分层练习（概念题→代码题→思考题），等学习者交答案后逐条诊断；
4. **④ 思考扩展**：留 1 个桥接下一节点的思考题。

**铁律**：先问后讲、一次只推一段、等学习者回复再继续；不一次性倾倒内容。**允许并鼓励画图**（SVG/交互式 HTML widget）辅助讲解，学习者可随时要求可视化。

### 3.3 打标与递推规则
节点完成的判定 = 费曼三准则全过：
1. 能用自己的话向外行讲清；
2. 能说出"不是什么"（举反例）；
3. 能迁移（换数据/任务/场景仍会用）。

通过后依次更新计划正文（在工作副本编辑后同步）：
- 「里程碑」：`- [ ] Nx` → `- [x] Nx`
- 「进度日志」追加：`日期 | Nx | 🟩已完成 | 一句话收获`
- 学习者暴露的误解追加到「误解本」：`日期 | 我曾以为 | 实际是 | 来源节点`
- 自动递推：下一节点从「① 提问启动」重新开始，并在进度日志记 `🟨进行中`

### 3.4 间隔复习
已完成节点在打标后第 1/3/7 天快速回顾（一句话复述核心 + 一个"不是什么"）。回答不上来则回炉，不撤销打标。

### 3.5 双端同步
每次编辑工作副本后，复制覆盖知识库正文：
`Copy-Item 工作副本 计划正文 -Force`

### 3.6 会话记录
每次会话结束或每完成一个节点，把对话要点登记进 `学习记录-会话NN.md`，工作副本与知识库 `scgpt\` 双写，NN 递增。记录四要素：学习者**原话回答**（引号）、**真实评价**（✓/◐/✗，标明哪对哪偏）、**主动提问**（深挖问答）、**错误清单**（◐/✗ 单独成节供回溯复习，间隔复习日抽问）。

## 4. 交互语法（学习者侧）

- `【Nx】开始`：跳转/启动某节点
- 直接回答编号内容：按当前段落继续诊断
- `卡在...`：降粒度重讲，或拆分当前节点
- 提问任意延伸问题：正常解答，但主线按节点走

## 5. 每日 9 点动态提醒（TRAE 定时任务）

- 任务名：`scGPT 每日学习提醒`（ID 854a5817，Asia/Shanghai，每天 09:00）
- 行为：读计划正文 → 定位当前节点 → 算 1/3/7 天复习队列 → 生成 ≤300 字提醒（节点位置 + 一个费曼式启动问题 + 今日建议动作；停留超 7 天则提示卡点）
- **迁移到其他工具时**：按上述行为逻辑重建等价定时任务即可，无需依赖 TRAE。
