## N0 scRNA-seq 数据基础 ✅

**提问启动**：① 细胞被读成一行丢失了什么 ② 矩阵里 90% 的 0 是什么意思 ③ 3万基因×5万细胞先看什么

**学习者直觉 → 诊断**：
- "丢失空间信息，且不一定一维" → 命中 spatial transcriptomics + 计数压扁，极准
- "少量数据不具统计学意义，只能模糊表达多少" → 命中 dropout/零膨胀
- "表达频度、种类" → 自推 marker 基因/差异表达

**概念**：表达矩阵=count 非表达水平；归一化 log1p(CPM)；HVG=高变≠高表达；降维=画地图、聚类=划地盘（PCA→UMAP 链条，N9"一个 PCA 打败一切"伏笔）

**练习**：A/C 同类（T 细胞，CD3D）✓，学习者归因偏差（"测序不准所以像"）被纠正为"标志基因模式"；零膨胀判断 ✓

**误解本**：曾以为分型看"哪个数字更像" → 实际看标志基因有无；管家基因不分型

## N1 Transformer 与语言模型 ✅

**提问启动**：① 基因有无顺序 ② 预测下一个还是猜盖住的 ③ 注意力怎么分配/交叉怎么办

**学习者直觉 → 诊断**：
- "不一定一维且单向，随机的" ✓ 基因袋无词序
- "猜盖住的，后者合理" ✓ 且与无序自洽（掩码建模不依赖顺序）
- "按重要性分配 + 追问通路交叉" → 软分配/多头是答案

**概念**：softmax=指数放大器（1.9 分差→6.7:1 概率比）；温度=旋钮；交叉基因=按比例混合；多头=多套关系系统（N10 造血流形伏笔）；softmax 永不给 0=可导性设计（梯度需流过所有权重）

**练习**：softmax 手算 (0.66/0.24/0.10) ✓；numpy 注意力：scores(1,0,0.7)→w(0.47,0.17,0.35)→输出 6.50，交叉基因把 7.31 拽向 5；B 占 17% 目光贡献 0（每个基因都被看一眼）

**思考扩展**："训练的是细胞表示=元信息，什么任务都能支持" → 学习者自推出基础模型定义

**可视化**：attention_softmax_demo——可拖打分/信息值，体验指数放大与软加权

**误解本**：曾以为 softmax 只是压掉数量级 → 实际是指数放大器

## N2 基础模型范式 ✅

**提问启动**：① 地基 vs 楼改哪里 ② 专用 vs 通用经济学 ③ 通用表示的失效边界

**学习者直觉 → 诊断**：
- "需要改的是楼，外接" ✓ backbone + task head
- "一种任务前者划算，一百种后者" ✓ 摊销经济学（N9 线性基线之争根源）
- "边界和训练数据集相关，新基因差异大会完全失效" ✓ 修正为三层：词表硬断裂 / 分布漂移 / 外推降级

**预问题诊断**：softmax 永不给 0 非怕数值不准，是可导性；GPT 无假 0（token 是"选出来的"符号，count 是"测出来的"物理量——类比的断裂点，BERT 掩码是人为假缺失）；参数=长期记忆（统计规律）、嵌入=运行时快照（512 维坐标）

**练习**：注释需外接分类头（B）✓；"参数存 33M 细胞矩阵"为假 ✓；BERT 直改三崩点——学习者诚实说不知 BERT 架构，猜中"词表先崩"（三崩点之一：词表/连续值/顺序）

**学习者提出的联想**："softmax 永不给 0 恰好契合 scGPT" → 判定为世界观巧合（生物调控渐变 vs 软注意力），非设计原因，可入心智模型

**可视化**：foundation_model_paradigm——三范式迁移时间线 + 地基/三楼外接图

## N3 scGPT 架构解剖 ✅（完成于 09-20）

**提问启动**：① 基因词表 vs 英语词表的优劣势 ② 数值怎么编码 ③ 位置编码用什么替代

**学习者直觉 → 诊断**：
- "基因更稳定；但基因可能没有语义，词袋无法体现" → 优势劣势全中，且自问出领域级问题（基因语义）——答案：分布语义，掩码预测把语义压进 embedding
- "出现+表达量整合成二维向量，不损失信息" → 方向对（融合），但真实实现故意有损：51 档分箱+查表+相加，"模糊的正确"
- "用相似基因向量/聚类提取" → 答在模型内部层面（那是注意力的活）；输入端实为无位置编码+按表达量降序（假顺序携带秩信息）

**概念**：60,536 固定词表（罕见基因≈生僻词）；51 箱按基因各自分布定界（同 count 落不同档）；√d_k=温度防 softmax 饱和；残差加法=梯度直通

**深挖问答（学习者主动提问）**：
- embedding 详解：60,536×512 查表矩阵（~3100 万参数），可学习=梯度下降改行；GPT 用 BPE 字节回退（永无 OOV）vs scGPT 固定词表（硬 OOV）
- 梯度消失：链式连乘衰减（0.25^10≈1e-6），softmax 饱和是近亲，残差是解药
- 512 维：2 的幂+工程甜点（O(n²·d) 成本），非理论上限（GPT-3 达 12,288，Geneformer 仅 256）

**练习**：① 相对值按基因箱体 ✓ ② "模糊的正确"排除测序误差 ✓ ③ 优先级排序（词表>排序>分箱）**与真实历史完全吻合**——UCE（Nature 2026）弃固定词表改 k-mer 编码，Geneformer 保留排序改全局 rank

**可视化**：`scgpt_input_encoding`（输入管线）、`embedding_geometry`（查表+空间簇）

**伏笔回收/新增**：分箱=测量包装成符号（N2 伏笔兑现）；假顺序为何有用→N4 完整解释+3300 万细胞数据管线；UCE 已提前在练习 3 兑现
