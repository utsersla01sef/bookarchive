## Cell 7 · 可视化：嵌入空间 → UMAP 地图

> 概念对应：降维 = 画地图（N0 补课）；类型染色 = 检验嵌入是否学到了生物学（而不是乱码）

```python
import umap, matplotlib.pyplot as plt
import numpy as np
emb2d = umap.UMAP(n_neighbors=15, random_state=0).fit_transform(cell_embeddings)
labels = adata.obs["louvain"].astype(str).values
for lb in np.unique(labels):
    m = labels == lb
    plt.scatter(emb2d[m,0], emb2d[m,1], s=4, label=f"cluster {lb}")
plt.legend(markerscale=2); plt.title("scGPT embeddings (PBMC 3k)")
plt.show()
```
