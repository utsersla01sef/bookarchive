# 0-计划 · 知识学习执行计划

> 存放**学习类**执行计划：学什么、用什么资料、什么顺序、进度如何。数量多后按主题建子目录，如 `0-计划/经典力学/`、`0-计划/育儿/`。

## 规则

- 一个学习计划一个 md，命名 `{主题}.md`；同主题多阶段可建子目录
- front-matter 只有一项：`状态: 计划 | 进行中 | 已完成 | 搁置`
- 计划中的资料用相对链接指向各分类 INDEX 或具体笔记，**不复制 MD5/ISBN**（单一来源原则）
- 完成后**不移走不删除**：勾选里程碑、状态改「已完成」，留档复盘
- 建库/维护类任务不在此处，记录在根目录 [初始化记录](../初始化记录.md)

## 学习计划模板

```markdown
---
状态: 计划
---
# {学习主题}

## 目标（学到什么程度）

## 资料（链接到 INDEX / 笔记 / 专题）
- [Classical Mechanics (Taylor)](../数学&物理/INDEX.md)

## 里程碑
- [ ] 通读第 1–3 章
- [ ] 完成笔记
- [ ] 复盘输出

## 复盘
```
