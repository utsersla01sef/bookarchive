# ER 图自动布局与可取消计算——设计经验与图论升级

## 为什么记

不是抄代码。一套"**大图自动布局 + 可中断重计算**"的完整工程解法，逆向分析后把**可迁移的思维模型 + 算法骨架**提炼出来，并附我对分类器的图论化升级（v2）。目标：换语言、换框架，凭本笔记也能复现。

**场景**：上千节点的表关系图（节点=表，边=外键），布局计算重（秒级），用户随时取消/切换/重新生成。三个硬需求：① 布局可读 ② 取消立即生效 ③ **过期任务的结果绝不上屏**。

---

## 一、值得学的六个经验（v1 精华）

### 经验 1：先分析数据形态，再选算法（领域驱动）

事实：ER 图外键**稀疏**——绝大多数表只有 0~2 个外键。因此图的主体是**孤立点和成对表**，大簇是少数。策略跟着分布走：

```
按连通分量分类：
  大簇(≥3节点) → 力导向（拓扑信息多，值得花迭代钱）
  成对(=2)     → 固定格摆放（唯一信息是"它俩相关"，
                 力导向跑一万轮也只能得出"挨着"——纯浪费）
  孤狼(=1)     → 填网格空洞（无任何约束，摆哪都对
                 → 哪有空塞哪，顺手让整体更紧凑）
```

**两个反直觉点**：
- 力导向处理无约束节点会**乱飞**（只受排斥力没有弹簧，无收敛点，位置全看随机初值）；
- "杀鸡用牛刀"的危害不只是浪费——**牛刀有自己的脾气**：强算法要在它不制造缺陷的地方用。

> 网格密度由最大分量定：1节点→1×1格，≤4→2×2，≤9→3×3，>9→4×4。所有格子最后按 ⌈√n⌉ 列拼成大网格。

### 经验 2：两级抽象（组内自组织 + 组间拼装）

```
for 每个分组: 组内布局 → 记录包围盒
把每个包围盒当作一个"虚拟大节点"（尺寸 = 包围盒 + 内边距）
虚拟大节点之间再做一次 力导向 → 去重叠 → 收缩
回填: 组内全部节点平移 (虚拟节点新位置 − 原包围盒中心)
```

要点：组内不管组间、组间不知道组内内部——两层只通过"包围盒 + 偏移"这个窄接口衔接。**忘加内边距回填后组会贴脸**。

### 经验 3：分类轴按"连通性"，不按"度数"

A→B→C→D→E 五表链：每个节点度数都是 1。按度数分类会把链拆散成"对"；按**连通分量**分类保留整体。关系的语义单位是**连通的一片**，不是"一个点连了几条线"。

### 经验 4：五层取消体系 ★（全笔记最值钱，与 ER 图无关，可整套搬走）

适用：任何"长任务 + 可并行 + 可中断 + 过期结果须失效"的场景。

```
层① 总闸        run = false; 通知所有后台计算单元
层② 阶段检查点   每个大阶段之间: if (!run) return
层③ 迭代级中断   重循环(力导向等)每步回调询问; 不等整轮跑完
层④ 双终止      后台线程: 先发协作退出消息(它在下个循环开头自查),
               不响应再 terminate 强杀兜底 —— 先礼后兵
层⑤ 双令牌对账   任务序号(防同类新旧覆盖) + 随机串(防异类切换);
               每个 await 之后核对, 过期结果直接丢弃
```

**为什么必须五层**：取消可能发生在任何时刻——总闸秒断、检查点断阶段、tick 中断断迭代、双终止对付不听话的线程、令牌兜住"来不及停的旧结果"。

**精髓在层⑤**：取消真正的难点不是"停不下来"，而是**没来得及停的旧结果不能污染新状态**。类比取餐号：过号作废。两个令牌是正交的失效维度——序号管"同类任务新旧"，随机串管"不同任务切换"。

附：**孤儿清理保护**——销毁中间状态前核对身份（是否是当前正被显示的那份），只清没在用的，防误杀。

### 经验 5：Worker 编排四细节

```
瘦身:  传给 Worker 的只是几何必需字段(id/x/y/w/h + 边两端id)
      —— 结构化克隆成本与对象图大小成正比
分片:  商+余数, 前几片多领一个; 数量上限 min(20, 任务组数)
心跳:  每完成一组回一条进度消息(既是进度也是存活信号)
降级:  不支持 Worker → 主线程串行同一布局函数, 结果等价
```

### 经验 6：渲染降本组合拳 + 序列化一次两用

- **lastRender 快照 diff**：渲染器记住"上次画成什么样"，更新时逐项比对（可见/高亮/选中/折叠/列宽…），多数变化只需显隐切换，结构性变化才全量重绘。把"哪变了"显式建模，比盲目重绘快一个量级
- 视口裁剪（外包盒与画布求交，看不见不画）；低倍率缩略（zoom<阈值只画外框）；字段默认折叠（**尺寸在建模期按折叠态预计算**——折叠是布局与渲染的共同前提）；脏矩形局部刷新
- **保存 = 全量模型快照**（元数据+每个节点坐标+分组+视口），打开 = 零计算直接还原；同一份 JSON 还可发给后端拼文档——**序列化只写一次，两个消费方**

## 二、v1 的四个漏洞（升级动机）

1. **分类轴太粗**：链/星/网/稠密团全进同一个"≥3 力导向"桶，拓扑结构全丢；
2. **忽略 DAG 性**：外键引用几乎不成环（表按创建依赖引用），FK 图天然是**稀疏 DAG**——DAG 有确定性分层布局，力导向的迭代与随机纯属浪费；
3. **窄结构不稳**：链、树在力导向下扭结震荡，且依赖随机初值不可复现；
4. **没利用可分解性**：稀疏图可做块-割点分解降维成树，v1 完全没做。

## 三、v2：图论化分类管线（升级方案）

```
comps = 连通分量分解                         O(V+E)
for c in comps:
  |c|==1            → 孤狼·填洞              (保留 v1)
  |c|==2            → 成对·定格              (保留 v1)
  是树 (E==V-1)     → 层次树布局              确定性 O(V)
  是路径(最大度≤2)   → 蛇形折叠布局            确定性 O(V)
  是星(唯一超级hub)  → 辐射布局               确定性 O(V)
  可拓扑排序(DAG)    → 最长路径分层            确定性 O(V+E)
  密度 ε=2E/(V(V-1)) ≥ 0.3 → 力导向          ← 唯一付迭代代价的类
  其余(稀疏有环)     → 块-割点分解 → 按树布局
```

**所有判定都是 O(V+E)**——预处理成本可忽略。v1 省下的不是计算钱，是实现的复杂度。

### 关键升级：longest-path layering（吃定 ER 图的 DAG 性）

```
拓扑序 → 每节点层号 = 前驱最大层号 + 1
层号定 y（层间距固定），层内定 x（拓扑序/重心启发排序）
两遍扫描，零迭代，同图必同结果；所有边方向一致向下，可读性碾压力导向
```

树/链/星都是 DAG 特例，分层自动覆盖；专用布局只是"更便宜更好看"的锦上添花。
可选增强：层内按邻居层号均值（barycenter）排序减少交叉。

### 备选通用底层：块-割点分解（Tarjan）

稀疏有环图的通用降维：DFS 低链接求**割点与桥** → 双连通块当**超节点** → 块间经割点连接天然成**树**（BC-tree）→ 树用确定性树布局摆好 → 块内再按上面规则分类（桥=直线、稠密块=力导向、其余=分层）。该路径覆盖全部特例（**树 = 全是桥的图**），想做统一实现可以从它起手。

### v1 / v2 对比

| 维度 | v1 | v2 |
|---|---|---|
| 分类轴 | 分量尺寸(1/2/≥3) | 结构类型 + DAG 性 + 密度 |
| 力导向面 | 所有 ≥3 分量 | 仅稠密团（占比很小） |
| 确定性 | 看随机初值 | 除稠密块外全确定 |
| 链可读性 | 扭成团 | 蛇形/分层一眼可读 |
| 计算成本 | 大分量 O(n²·迭代) | 主流分量零迭代 |
| 适用域 | 已知稀疏小簇分布 | 通用图成立（v1 降级为工程简化版） |

## 四、复现路线图（最小落地顺序）

1. **数据结构**：节点必须含 w/h（折叠态尺寸）——布局需要真实几何，只有 id/x/y 不够
2. 连通分量：Map + 双向邻接表（别用线性 find，会退化 O(V²)）
3. v2 分类器 + 树/链/星/DAG 四个确定性布局（**先不做力导向**——已覆盖 ER 主流）
4. 两级拼装（包围盒 / 内边距 / 回填）
5. 力导向（**带 shouldContinue 每 tick 询问**）+ 去重叠/收缩（必须 maxPasses 上限）
6. Worker 编排 + 五层取消骨架（层⑤令牌贯穿每个 await 之后）
7. 渲染优化按需（lastRender diff 优先级最高）

**验收三条**：同输入两次布局输出 diff 为空（确定性）；任意时刻取消 ≤ 1 tick 延迟；过期任务结果不上屏。

## 五、反模式清单（分析中发现、别照抄）

- 重生成 = 推倒重来（无增量合并）→ 大图全量重拉，应做节点/边 diff 后局部重建
- 力导向里对无约束节点不设防 → 孤狼乱飞
- 去重叠无轮次上限 → 死循环
- 组间虚拟节点忘加内边距 → 回填后贴脸
- 取消只放一个布尔标志 → 旧结果照样回来覆盖新画面
- 保存"截图式"快照 → 不可再编辑；要存模型 + 坐标
- 微浪费：档位数组每次缩放重新排序等
