# How I use LLMs to learn complex topics

> 作者观点整理；原文与中文摘要见 [assets](assets/how-i-use-llms-to-learn-complex-topics.md)。

## 问题

- LLM 默认的讲解风格偏简化、信息密度低，难以消化
- 纯读检索到的资料、或看模型列的要点清单，记忆留存差

## 方法（四步）

1. 用编程 Agent 的 **plan 模式**让模型先为某主题搭建基础知识库
2. 让模型**自查**该知识库的准确性
3. 让模型基于知识库生成**低多边形、模拟经营游戏风格的交互动画**（响应式、可暂停、大屏小屏可用）
4. 发布到 GitHub Pages

## 效果与实例

- 产出可视、可交互、无幻觉（知识库先行+自查）的学习动画，比文字材料记得牢
- 实例 ChipTycoon：跟随小车从采砂到芯片交付数据中心，全程走完制造链路
- 同系列：火箭发动机、LLM 原理（Token Town）、F1 发动机、EUV 光刻机

## 进阶

- 用「图片转 3D 资产」的 skill 把低多边形升级为更真实的表示
- 给模拟加**问答与谜题挑战**（如回答上一环节的问题）强化记忆
- 作者开源了 learnscape（专门生成学习动画的 SKILL.md）
