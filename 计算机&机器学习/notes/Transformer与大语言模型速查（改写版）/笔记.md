# Transformer 与大语言模型 · 知识要点

> 本文为**全文改写版**：依据原速查表的知识点重新组织表述，未保留原文句段；公式与结论等价。

## 1. 词元与表示

- 文本先被切成 **token**（词表中的最小单元，可为词/子词/字符）；`[UNK]` 占位未知片段，`[PAD]` 补齐定长
- 分词粒度三档取舍：
  - **词级**：序列短、好理解，但词表庞大且难处理词形变化
  - **子词**（BPE、Unigram 为主流）：利用词根、嵌入直观；代价是序列变长、切分复杂
  - **字符/字节级**：不存在未登录词、词表极小，但序列过长、模式难学
- **嵌入**：把离散 token 映射为向量；两向量的夹角余弦度量相似度，取值 [-1,1]
- 海量向量的高效近邻检索依赖 **ANN**（近似最近邻）与 **LSH**（局部敏感哈希）

## 2. 注意力机制

- 单头注意力的矩阵形式：`softmax(QKᵀ/√dₖ)·V`——用查询 Q 对键 K 打分（除以 √dₖ 稳定数值），对值 V 加权求和
- **多头注意力（MHA）**：并行跑 h 组独立投影的 Q/K/V，拼接后经输出矩阵映射，让不同头关注不同关系
- 降本变体：**GQA**（分组共享 K/V）、**MQA**（全部头共享一组 K/V），削减 K/V 的显存与带宽

## 3. Transformer 架构

- 双塔结构：**编码器**产出输入的语义嵌入；**解码器**在此基础上自回归地预测下一 token
- 编码器层 = 自注意力 + 前馈网络；解码器层额外含**掩码自注意力**（看不见未来）与**交叉注意力**（读编码器输出）
- **位置编码（PE）**：注入词序信息；分固定式与可学习式。**RoPE** 通过旋转 q/k 向量把相对位置揉进注意力点积，利于长程依赖
- 三种骨架：
  - **仅编码器**（BERT）：堆叠编码器，句首 `[CLS]` 的向量供下游分类等任务
  - **仅解码器**（GPT 系）：当代主流 LLM 形态（GPT/LLaMA/Mistral/Gemma/DeepSeek 等）
  - **编码器-解码器**（T5 类）：同样具备自回归生成能力
- 计算优化：
  - 注意力关于序列长度是 O(n²)；可用**稀疏注意力**（只在相关 token 间计算）或**低秩近似**压缩
  - **Flash Attention**：不近似、精确；把矩阵乘放进快速 SRAM、再写回慢速 HBM，同时省显存、提速度

## 4. 大语言模型训练三部曲

预训练（通用语言知识）→ 微调（对齐目标任务）→ 偏好调优（压低不良输出）；后两步合称后训练。

### 4.1 提示与解码

- **上下文长度**：模型一次能处理的 token 上限，从数万到百万级不等
- **温度 T**：采样分布的锐度旋钮——高温多样、低温确定
- **思维链（CoT）**：让模型先写中间步骤再作答；**ToT** 扩展为树状推理；**自洽性** 对多条 CoT 路径投票取稳

### 4.2 微调

- **SFT**：高质量输入-输出对监督训练；数据为指令格式时称指令微调
- **PEFT** 家族省参数：**LoRA** 把可学权重近似为冻结原矩阵加低秩乘积 `W ≈ W₀ + BA`；另有前缀微调、适配器插入

### 4.3 偏好调优

- **奖励模型（RM）**：给 (输入, 输出) 打契合分；**Best-of-N**（拒绝采样）从 N 个候选中挑 RM 最高分
- **RLHF**：用 RM 的奖励信号经强化学习更新策略；**PPO** 在提分与限制偏离原策略间平衡，防 reward hacking
- **DPO**：把奖励建模与 RL 合并为一步监督训练，流程更简

### 4.4 推理期优化

- **MoE**：门控网络按输入只激活部分专家网络，推理算力大降；但训练难度高（LLaMA 因此未采用）
- **蒸馏**：以大教师模型的软标签（KL 散度损失）训小学生模型
- **量化**：FP32 → INT8/BF16 等低位宽，模型变小、推理更快；**QLoRA** 为 LoRA 与量化结合的常见做法

## 5. 应用形态

### 5.1 LLM 当评审（LaaJ）

- 依据评分标准打分并**给出评分理由**，不依赖参考文本
- 三类系统性偏差及对策：
  | 偏差 | 表现 | 对策 |
  |---|---|---|
  | 位置偏差 | 成对比较偏爱排前者 | 打乱顺序、多轮平均 |
  | 冗长偏差 | 偏好更长的输出 | 长度惩罚项 |
  | 自我增强 | 偏爱自己生成的内容 | 换不同基座模型建评审器 |

### 5.2 RAG

- 检索器从外部知识库取相关文档注入上下文，弥补预训练截止后的知识缺口
- 知识库构建 = 文档切块（块大小 n_c）+ 逐块嵌入（维度 d）；检索常用仅编码器模型产出的向量

### 5.3 智能体（Agent）

- 多轮 LLM 调用链自主完成任务；**ReAct** 循环 = 观察（总结已知）→ 计划（定任务与工具）→ 行动（调 API/检索）
- 评估可按组件级输入输出或整链路进行

### 5.4 推理模型

- 靠显式 CoT 轨迹攻坚数学/编程/逻辑（o 系列、R1——推理过程写在 `<think>` 标签内等）
- 能力扩展两路：**训练时**（更长 RL 训练学会输出 CoT）与**测试时**（提示语让模型"多想一会儿"）
